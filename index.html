Foam Impact Design Calculator

Web tool for this project: the textbook’s iterative impact method is implemented as code and parameterized using Polyethylene and Cross-linked Polyethylene foam data (Foam Factory technical sheets). The two yellow columns on the right are the key results: optimum foam thickness and optimum relative density.
